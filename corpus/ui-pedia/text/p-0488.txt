2. Engage the user through their journey
A user's goal when interacting with a website or user
interface is to complete a certain task. Their user journey is
made up of the steps they toke to complete that task. The
usage of Ul graphics can help designers create interfaces
that improve the user journey (and thus the user
experience).
You can use graphics to interest the user and make the
procedure easier in this instance. This is very helpful for
creating long or complicated onboarding processes.
