Whot is Visual Weight?
Visual weight is a force that draws a viewer's attention.
Every object on the page carries a certain amount of
weight. The more weight an object carries, the more
attention it attracts. We can use visual weight to generate
focal points (olso known as visual magnets or points of
attraction) - things with more visual weight than others.
