1. Customize grids according to your design needs
Grid youts ore frequently used to control the proportions
and connections between page elements. As a result, you
must adapt the grids to meet your design requirements.
There are a few things to think about:
Customize columns and rows
Visual designers frequently ask the following questions
when working with grids:
• How many columns nd rows should be used?
• What columns width and row height should I choose?
• Is it necessary to set the block size or gutter width?
Before you begin working with the grids, you should ask
yourself these questions. It's great if you always customised
these settings according to your layout requirements.
You can start with a 12-column grid if you don't want to
develop a bespoke grid arrangement.
