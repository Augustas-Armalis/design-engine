Choosing the Right Curve (Corner R1dius)
If you're utilising rounded buttons, make sure the rounded
corner rotios of other on-screen objects are correct. Using
the same one for everything will result in margin
imbalances.
Buttons can be differentiated by their corner radius.
Remember that each project is unique; if your brand image
consists solely of shorp corners, hoving rounded buttons will
result in an inconsistent user interface. Unless done on
purpose, mixing a few of different corner radiuses inside one
interface can lead to issues with consistency and
readability.
