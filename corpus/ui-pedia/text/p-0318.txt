3. Placement
Try to adopt common Ul patterns and traditional layouts as
much as possible when putting o UX button, as traditional
button placement improves discoverability.
Even if it's only a button with no other compelling visual
clues, using a standord layout will assist consumers
understand what each element's purpose is. The layout is
clearer when a standard layout is combined with ample
whitespace and a clean visual design.
