Augustas (2026-10-09): the engine will power "X" work, and separately the same engine should design client websites for the Larpo team and then review what is already built and fix it. Later it becomes a product with more logic and automation. Current priority: keep refining design quality, especially dark mode, bento visuals, typography, buttons, shadows, motion, and above all consistency (radius, icon centring).

**Why:** this is the long-term shape of the tool; review-and-fix is a first-class mode, not an afterthought.
**How to apply:** when given an existing site/repo/screenshot, run the review-and-fix mode in the repo's CLAUDE.md (measure, REVIEW.md with evidence, fix, re-check). See [[design-engine-project]] and [[founder-kestrel-bar]].
