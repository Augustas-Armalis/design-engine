# Weft: direction (retry after the Overlap reject, 2026-10-20)

**Brief:** a post-worthy component card and a clean, professional hero. Overlap was rejected as "too hollow", so this round is built to Kestrel/Quorum density.

**One line:** Weft is an AI workflow builder for support, billing and ops. AI steps read context, ask a person when it matters, then act. Proof: a live sample run (ticket #48211, refund $248.00, AI reads "refund 0.92", the branch routes to approval, the run waits on Maya).

## Hero class
Product proof: centred copy (Kestrel floor) over a halftone stage holding the full workflow editor (topbar, canvas with 5 nodes and edges, AI output, run inspector with the approval).

## What fixes "hollow"
- A real app with its chrome: breadcrumb, Live badge, Editor/Runs/Versions, search ⌘K, avatars, Test run / Publish, zoom control, inspector.
- 30+ data points that tell one coherent story.
- A material field: the halftone dither, violet to magenta to apricot (Kargul post grammar, our own palette).
- One decision moment: the approval. The post shows it at about 58% of the square, with the cursor on Approve.

## Divergence
- New product world: a workflow canvas.
- New material: halftone dither instead of a grain gradient or the dot map.
- Type: Geist 58/560 instead of Inter.
- Colour: violet only for AI steps; green and amber only for run state.
